# 红果TV

在电视和投影上看漫剧、短剧，也能用手机选剧、选集和控制播放。

基于 Kotlin 与 Media3 的非官方 Android 客户端，支持 **Android 8.0 及以上**。安装 APK 后联网即可使用，无需部署后端。

**[下载最新版 APK](https://github.com/laozhangaa/HongGuoTV/releases/latest)** · [版本记录](https://github.com/laozhangaa/HongGuoTV/releases) · [构建说明](kotlin-tv/README.md)

## 主要功能

- **发现好剧**：漫剧、短剧分类浏览，剧库筛选、关键词搜索和热播排行榜。
- **追剧与续播**：本地收藏、最近观看、断点续播与收藏更新提示。
- **红果账号**：账号管理，查看账户收藏、观看历史，以及短剧预约中的已上线和待上线作品。
- **播放控制**：选集、上下集、倍速、清晰度、画面模式和定时停止；支持自动连播与下一集预载。
- **手机遥控**：扫码打开网页，搜索选剧、浏览剧库、点播选集，以及暂停、继续、快进快退和调节倍速。
- **在线更新**：从本仓库 Releases 检查和下载新版，确认后覆盖安装，保留本机记录。

清晰度最高可选 1080P，实际画质取决于片源；播放与预载效果取决于设备和网络。

## 开始使用

1. 从 [Releases](https://github.com/laozhangaa/HongGuoTV/releases/latest) 下载 APK，安装后打开「红果TV」。
2. 用电视遥控器浏览、搜索，打开剧集详情后选集播放。
3. 需要手机操作时，让手机与电视连接同一局域网，扫描首页或「手机遥控」中的二维码。电视应用保持打开即可，无需安装手机端。

账户收藏、账户历史和短剧预约需要先在「设置 → 红果账号管理」中登录；本地收藏与观看记录可直接使用。

## 版本更新

应用在前台浏览时检查新版，只提示、不自动下载，播放中不打扰。也可进入「设置 → 版本与更新」手动检查，按提示下载并确认系统安装。

**v0.10.17 及更早版本请先手动安装一次 v0.10.18 或更新版本**，以切换到本仓库的更新渠道。覆盖安装请使用相同包名、相同签名的正式 APK。
