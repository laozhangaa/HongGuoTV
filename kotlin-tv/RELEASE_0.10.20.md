# 红果TV 0.10.20

版本 0.10.20 / versionCode 37，最低 Android 8.0（API 26），沿用既有正式签名。

- 修复播放接口持续返回空响应后，自动重试仍反复使用同一份缓存会话、只能重启应用恢复的问题。
- 连续 3 次空响应后允许重新初始化一次匿名播放会话，再获取播放地址；普通短暂空响应仍沿用现有会话。
- 搜索、播放和下一集预载共享恢复结果，并限制 60 秒内最多一次会话重建，避免并发请求或自动重试重复初始化。明确的 HTTP 拒绝不触发此恢复。
- 保留当前播放集数、续播位置和画质选择。此修复针对已复现的空响应，不代表所有网络或平台服务故障都能自动恢复。

同包名、同签名覆盖安装保留本机数据。v0.10.18 及以上版本可通过本仓库 Releases 更新；更早版本请手动安装一次。
