# 红果TV 0.10.14

版本 0.10.14 / versionCode 31，包名 `com.hongguotv.laozhangapp`，最低 API 26，沿用 tudou 签名。

## 修复自动连播停顿

0.10.13 保留了上一集最后一帧，但仍在本集结束后重新设置媒体源。用户日志显示 12:39:59.885 结束、12:40:01.511 下一集开始，间隔约 1.626 秒。模拟器中的应用日志还确认 `preloaded=false`：系统将 Wi-Fi 标记为按流量计费，旧策略禁用了预载。

- 下一集完成地址解析和前 2 MiB 预读后，提前加入同一个 ExoPlayer 的播放列表；启用队列预加载，目标为下一集前 5 秒。
- 自动连播由播放器推进到已准备的队列项，更新电视与手机上的集数、观看记录、定时停止状态。自动衔接不再重新设置媒体源或调用 prepare。
- 手机选择已入队的下一集直接跳到对应队列项，保留已有缓冲。任意其它集数仍按需加载。
- Wi-Fi 和有线网络允许预载，包括被系统标为计费的热点网络。计费移动网络继续使用原有预载限制。
- 队列只保留当前集和下一集；取消、切换、退到后台及退出时移除预载项并关闭其专用连接。已播放资源延迟 1.5 秒关闭，退出时一并清理。
- Media3 仍为 1.11.1，继续使用一个播放器和一个画面层。
