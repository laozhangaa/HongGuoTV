# 红果TV 0.10.16

版本 0.10.16 / versionCode 33，包名 `com.hongguotv.laozhangapp`，最低 API 26，沿用 tudou 签名。

## 页面与加载动效

- 切换主导航时，导航保持可见，内容按目的页方向做 180ms 轻移和淡入；快速连续按键可打断过渡，动画不阻塞输入。
- 剧库、搜索、排行榜、剧集详情及空的云端列表增加原生加载占位。海报占位按窗口宽度与字体大小计算列数；耗时请求延迟显示细线进度，避免快速响应时闪动。
- 数据到达后，结果区短暂淡入；异步海报使用 140ms 交叉淡入，内存缓存海报直接显示。
- 首页同来源刷新保留已挂载的扫码模块、海报、滚动位置与焦点，结果相同时跳过重建。重复确认当前导航也不会再次重建页面。
- 系统关闭动画时，页面与海报直接切换，加载文字和静态占位仍可见。加载进度随页面退出或应用隐藏停止。

## 验证

Release 构建和 lintRelease 通过（0 errors、42 warnings，含按代码构造的 TvLoading 缺少 XML 构造器提示）。首次构建遇到本机 JDK C2 编译线程访问冲突，使用 TieredStopAtLevel=1、2 个构建 worker 后成功；该参数仅用于构建，没有修改应用运行配置。

已在 MuMu Android 15、1920×1080 模拟器覆盖安装，保留应用数据。检查了快速切页、剧库/榜单加载、搜索、详情占位到真实内容、首页刷新和返回。检查期间未发现 AndroidRuntime 崩溃。

字体 1.3 倍、深色模式与系统关闭动画的组合检查通过；随后恢复字体 1.0、动画倍率 0.5、原夜间模式 no。搜索测试后恢复原漫剧偏好。

首页底部点击刷新，对比加载前、加载中及完成后的同一海报区域，像素差异为 0，确认没有被清空或挪动。最终一次 10 次切页的 gfxinfo 记录为 112 帧、0 个 janky frame，P99 12ms；这是单台已预热模拟器的观察结果，不代表投影/电视实机或网络延迟。旧版和首轮结果亦保留在验证目录，不将不同样本作为严格性能基准。
