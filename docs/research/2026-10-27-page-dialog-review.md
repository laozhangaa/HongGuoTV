# 电视端页面与弹窗检查

范围：首页、剧库、搜索、排行榜、短剧预约、收藏、最近观看、设置、剧集详情、播放控制，以及筛选、选集、倍速、清晰度、后续季、账号、备份和更新弹窗。

改动前备份：`backups/before-page-dialog-polish-20261027-150956`。

## 已确认的问题

| 页面或组件 | 源码证据与影响 | 修正方向 |
| --- | --- | --- |
| 首页内容类型 | 热门列表始终使用漫剧优先的混合列表，选择短剧后标题与海报不一致 | 按选中类型展示对应热榜并缓存 |
| 搜索、排行榜、收藏、历史 | 固定六列且卡片最低 100dp，窄屏侵入安全边距 | 按可用宽度和字体大小计算列数，焦点同步 |
| 顶部导航 | 品牌和八个菜单直接横排，窄屏或大字体挤压尾部菜单 | 菜单随焦点横向滚动 |
| 详情页操作 | 播放、收藏、账户收藏、简介始终一行 | 空间不足时换行；选集列数适配 |
| 播放控制 | 左右仅约 1.5% 留白，与页面安全区不一致 | 控制层复用页面安全边距 |
| 账户弹窗 | 使用系统 AlertDialog，输入框、说明、焦点与其他弹窗不同 | 统一 TV 弹窗和输入框，保留登录生命周期 |
| 选集侧栏 | 最低 300×420dp 可能超过实际窗口 | 尺寸不超过可用窗口 |
| 通用及后续季弹窗 | 内容测量忽略父级约束，标题和底部操作可能越界 | 整体限高，正文让出底部按钮空间；操作支持换行 |
| 本机历史、收藏及账户列表 | 首次切换会发起空加载并覆盖本机列表；实机上首页有续播卡片但历史页为空 | 本地列表直接展示，账户刷新独立进行，不发起空的内容请求 |
| 空内容及未登录页面 | 默认选中预览与空状态重复；预约未登录提示出现两遍且没有直接入口 | 空列表隐藏预览及重复状态，提供登录按钮 |
| 小屏首页 | 内容类型按钮缺安全留白；扫码横幅过早堆成纵向 | 补同一边距，中等宽度保留二维码在右侧 |
